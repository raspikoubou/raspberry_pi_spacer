# raspberry_pi_spacer

Raspberry PiとHAT基板の間に取り付ける、基板間隔15mm用スペーサーのSTLデータです。

[製品情報・お問い合わせ](https://raspikoubou.theshop.jp/items/119161486)

| ファイル | 内容 |
| --- | --- |
| `raspberrypi_15mm_spacer.stl` | 15mmスペーサーの3Dモデル（バイナリSTL） |

製品は、らずぱい工房製HAT基板など、基板間隔15mmの用途向けに設計しています。形状・寸法はスライサー等で確認し、取り付け先との適合をご確認ください。

## 3Dプリントについて

製品ページに記載の材料はPLAです。積層ピッチ・充填率・造形方向・サポートの推奨条件は、本リポジトリでは未記載です。使用するプリンターや材料に応じて設定し、試作して寸法と強度をご確認ください。

試作・実験用途を想定しています。高温環境や強い力が加わる用途では、変形・破損にご注意ください。
